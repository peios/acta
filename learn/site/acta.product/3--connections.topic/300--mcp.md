---
title: "Connecting an Agent through MCP"
type: how-to
description: >-
  Approve an MCP connection, choose its identity and grants, and read the
  agent guide.
---

Acta exposes structured tools through the Model Context Protocol (MCP). A
connection's approved tools and the selected account's permissions both limit
what it can do.

## Before you start

Use a client that supports Streamable HTTP and OAuth. Know the installation's
canonical origin and the human or owned-agent identity you intend to
authorize.

## Connect and verify

1. Add the installation's `/mcp` URL in the client's MCP settings.
2. Start its authorization flow and sign in to Acta in the browser.
3. Check **Act as** and select the intended identity.
4. Approve only the tool categories needed for the work.
5. Ask the client to read `acta_guide`. If identity access is granted, use
  `whoami` to confirm the account.

For the local development server, the endpoint is `http://localhost:8081/mcp`.
An installation at `https://tasks.example.com` uses
`https://tasks.example.com/mcp`. The endpoint must match the configured public
origin; redirects do not substitute for the intended token audience.

## Change access

Open **User Settings → Security** for a human connection, or the owned agent's
page for an agent connection. Use **Edit access** beside the MCP session.
Saved changes apply to subsequent requests; already running requests are not
canceled. A client that caches its tool list can need a discovery refresh.

Adding tool access does not grant missing workspace permissions. Removing all
data-access grants leaves the guide available while preserving the connection.
Revoking the session removes the entire connection, including its refresh
tokens.

## Apply guide preferences

**User Settings → Guide** displays the same combined guide returned to agents.
User preferences take precedence over conflicting site defaults. Neither
expands permissions. Use these appendices for short, essential policy; keep
selectively useful conventions in memories and task-specific directions on
tasks.
