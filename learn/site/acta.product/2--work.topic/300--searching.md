title: "Finding Tasks"
type: how-to
description: >-
  Search across workspaces and task depths, inspect matching comments, and
  include archived work.
---

Global task search finds work beyond the current board or saved view. It
searches titles, descriptions, and comments across the workspaces you can
access.

## Search for work

1. Select **Search** in the sidebar, or press <kbd>Ctrl</kbd>+<kbd>K</kbd>
  (<kbd>Cmd</kbd>+<kbd>K</kbd> on macOS).
2. Enter at least two characters. Use a reference when you know it, or words
  that describe the work.
3. Narrow the search to a workspace if needed.
4. Open a result and read its description and relevant discussion.

A comment match opens the matching discussion even if it is outside the loaded
activity window. The task still applies its normal access checks when opened.

## Search beyond active work

Desktop search has **Include archived**. The command-line client and MCP
search also expose this choice. Active-only search does not prove that work
has never been tracked.

Search matches words and prefixes; it does not understand equivalent meanings
or correct spelling errors. Try alternative wording before creating a task.
For a complete inventory, use task lists and follow every relevant hierarchy
level and page rather than treating search as an export.

## Check the result

Confirm the task's workspace, requirements, and status. Similar titles can
refer to different work. If no suitable record exists after a reasonable
search, create a task in the intended workspace.
